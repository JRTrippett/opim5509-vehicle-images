# OPIM 5509 Assignment 4: Sedan vs. SUV images

Balanced two-class subset (129 sedan, 129 SUV) used for a ConvNet assignment.

## Changes made
- Kept only the `sedan` and `suv` classes (dropped hatchback, pickup, motorcycle)
- Used all 129 SUV images and randomly sampled 129 of 400 sedan images (seed 5509)
- Labels are unchanged from the original dataset
